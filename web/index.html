API rehberi

Ajana verilecek en kısa yol: okuma uçları token istemez.

Okuma uçları token gerekmez

  • GET /api/health — servis durumu, model ve görev sayıları
  • GET /api/catalog?view=models&limit=40 — model kataloğu
  • GET /api/pools — havuz kategorileri, /api/pools/<id> — bir kategorinin modelleri
  • GET /api/quotas — bağlantı başına önbelleklenmiş kota (canlı sorgu: GET /api/quotas/<routeId>?live=1 + Bearer token)
  • GET /api/select?kind=write&mode=execute — görev için model önerisi (göndermeden)
  • GET /api/help[?code=X] — servis haritası veya tek hata kodunun açıklaması
  • GET /api/capabilities, GET /api/connections

Görev uçları Bearer token

  • POST /api/tasks — gövde: {prompt, workspace, kind, idempotencyKey, mode?, routeId?, modelId?, group?, effort?}
  • GET /api/tasks/<id> — görev durumu/sonucu, POST /api/tasks/<id>/cancel
  • POST /api/tools/<tool> — herhangi bir havuz aracı (gövde = argümanlar)

CLI tokenu kendi yönetir

  • cli-agent-pool status — bağlantılar, kotalar, havuzlar, katalog
  • cli-agent-pool quotas [--route <id>] [--live] — tek bağlantının kotası
  • cli-agent-pool pools --group <id> · cli-agent-pool catalog --view models
  • cli-agent-pool model --route <id> --model <id> · cli-agent-pool help-code --code <KOD>
